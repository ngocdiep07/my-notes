Ghi chú về lệnh Git
git init: Khởi tạo một Git repository mới trong thư mục hiện tại.
git status: Kiểm tra trạng thái của các tệp trong repository.
git add: Đưa tệp hoặc thay đổi vào khu vực staging để chuẩn bị commit.
git commit: Lưu các thay đổi vào lịch sử Git với một thông điệp.
git push: Đẩy các commit từ máy tính lên repository trên GitHub.
